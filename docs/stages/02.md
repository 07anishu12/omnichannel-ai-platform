## Decisions A–D (implemented)

- **A.** Split `MYSQL_*` variables are canonical. `DATABASE_URL` is not defined anywhere in the API or Compose configuration.
- **B.** `AI_SERVICE_URL` defaults to `http://127.0.0.1:8000`. Production requires it. Trailing slashes are normalized. Only http and https are accepted. `AI_SERVICE_TIMEOUT_MS` is bounded to 60000 ms.
- **C.** `APP_ORIGIN` defaults to `http://127.0.0.1:3000`. Production requires it. Only http and https origins are accepted, and the stored value is origin-only.
- **D.** `deploy/local/compose.yaml` takes `MYSQL_PASSWORD` and `MYSQL_ROOT_PASSWORD` from required environment interpolation (`${VAR:?...}`). The MySQL healthcheck reads the root password from the container environment. No credential literals remain in Compose.
